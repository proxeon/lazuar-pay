# Glossary

| Term | Meaning |
|------|---------|
| **BYOK** | Bring your own keys — merchant’s gateway credentials in Hub vault |
| **Workspace** | Hub tenant / organization isolation unit |
| **Machine key** | `sk_test_` / `sk_live_` server credential |
| **M2M** | Machine-to-machine (server HTTP, no browser session) |
| **Integration checkout** | Ad-hoc amount checkout session for external apps |
| **Outbound webhook** | Hub → your app signed POST |
| **Inbound webhook** | Gateway → Hub provider callback |
| **Provision** | Create/bind workspace + bootstrap key for an external tenant |
| **MoR** | Merchant of Record — Hub is **not** MoR for guest GMV |
| **Dual-run** | Aura mode keeping legacy adapters during migration |
| **Opaque metadata** | String map Hub stores/returns without domain logic |
